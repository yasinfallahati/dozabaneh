# دوزبانه (dozabaneh)

Local web app that adds subtitles in up to two languages to any video, offline.

ویدیو را بارگذاری کنید، زبان زیرنویس‌ها را انتخاب کنید و ویدیوی زیرنویس‌دار یا فایل SRT بگیرید. همه‌ی پردازش روی سیستم خودتان انجام می‌شود.

## امکانات

- یک یا دو زبان زیرنویس هم‌زمان، از میان حدود ۱۲۰ زبان
- تبدیل گفتار به متن با Whisper و ترجمه‌ی آفلاین با NLLB
- پیش‌نمایش و ویرایش متن زیرنویس‌ها کنار ویدیو
- خروجی ویدیوی MP4 با زیرنویس چسبیده یا فایل SRT برای هر زبان
- پشتیبانی از متن راست‌به‌چپ و ویدیوی عمودی
- دکمه‌ی «نصب پیش‌نیازها» برای دانلود یک‌جای مدل‌ها (حدود ۲٫۷ گیگابایت)

## پیش‌نیازها

- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- ffmpeg با پشتیبانی libass:

```bash
sudo apt install ffmpeg
```

## اجرا

```bash
./run.sh
```

بعد `http://127.0.0.1:8765` را در مرورگر باز کنید و دکمه‌ی «نصب پیش‌نیازها» را بزنید. بسته‌های پایتون در اجرای اول خودکار نصب می‌شوند.

برنامه فقط روی همین سیستم در دسترس است و ویدیوها در پوشه‌ی `data` می‌مانند.

## تست

```bash
uv run pytest
```

## نکته‌ها

- پردازش روی CPU انجام می‌شود و برای ویدیوی طولانی زمان می‌برد.
- بسته‌های پایتون از میرور لیارا نصب می‌شوند. برای استفاده از PyPI، بخش `tool.uv.index` را از `pyproject.toml` بردارید و `uv lock` را اجرا کنید.
